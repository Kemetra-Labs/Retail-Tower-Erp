# tools/history

Generated by `build.sh` for the private, **non-authoritative** `Kemetra/Retail-Tower-Shadow` repository (RT-710, G1 + R4).
Do not edit by hand: regenerate from `frozen.tsv`.

- `frozen.tsv`: product, subdirectory, source repo, frozen `main` SHA, in import order.
- `crosswalk/<product>.tsv`: `old_sha, new_sha, old_tags` for every imported reachable commit.
- `crosswalk/tags.tsv`: every imported tag, old and new name and target.
- `refs/<product>.tsv`: every live source ref with its disposition (IMPORTED or EXCLUDED) and reason.
- `callbacks/<product>.py`: the commit callback that rewrites `#N` references and adds the `Original-Commit:` trailer.
- `repo-ids.tsv`: GitHub repository IDs of the sources.

This tree is not an authorization to publish. The pre-public full-history security and license gate is separate.
