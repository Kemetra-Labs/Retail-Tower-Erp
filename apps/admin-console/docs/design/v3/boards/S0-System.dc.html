بطاقة القرار

ماذا حدث → لماذا يهم → من يستطيع (دائمًا) → زر واحد يفتح شاشة موجودة، بنفس الاسم في كل مكان. الأولى فقط زر أساسي؛ الباقي أزرار ثانوية. النقطة الملوّنة لا تحمل المعنى وحدها.

جدول العمل

جدول كامل العرض، لا داخل بطاقة. بحث + مرشحات على شكل رقائق. الصف يفتح درجًا جانبيًا يحافظ على مكانك. حالة واحدة لكل صف كرقاقة نصية.
